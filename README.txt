NAPS3 0.8.4 — сканирование в РЕД ОС и Windows
=================================

Главное изменение
-----------------
Интерфейс полностью переведён с Tkinter на GTK 3 / PyGObject по образцу
приложений РЕД ОС.

Новая версия использует:
• системную тему РЕД ОС;
• нативную верхнюю панель HeaderBar;
• стандартные системные кнопки и символические значки;
• нативные диалоги открытия и сохранения;
• системные окна ошибок и подтверждений;
• правильное приложение GTK с идентификатором ru.redos.NAPS3;
• системную иконку NAPS3 в панели задач и меню приложений.

Сохранённый функционал
----------------------
• сканирование со стекла;
• односторонний и двусторонний автоподатчик;
• получение всех страниц через sane-airscan;
• цвет, оттенки серого и чёрно-белый режим;
• A4 и US Letter;
• 150, 200, 300 и 600 dpi;
• миниатюры страниц;
• большой предпросмотр;
• изменение масштаба;
• поворот страниц;
• изменение порядка;
• удаление отдельных страниц и очистка проекта;
• импорт изображений;
• импорт многостраничного PDF;
• сохранение одним PDF;
• сохранение одним многостраничным TIFF;
• сохранение выбранной страницы изображением;
• сохранение всех страниц отдельными файлами;
• отдельный одностраничный PDF для каждой страницы;
• PDF, PNG, JPEG, TIFF, BMP и WebP;
• русские сообщения об ошибках;
• сохранение настроек между запусками.

Установка или обновление
------------------------
Распакуйте архив и выполните:

  cd ~/Загрузки/NAPS3
  sudo ./install_redos8.sh --user имя_пользователя

Затем полностью закройте старый процесс:

  pkill -f /opt/naps3/naps3.py 2>/dev/null || true

Запуск:

  naps3

Зависимости интерфейса
----------------------
Новая версия больше не использует Tkinter и python3-pillow-tk.

Установщик использует:
• python3-gobject;
• gtk3;
• python3-pillow;
• sane-backends;
• sane-backends-drivers-scanners (если драйверы вынесены в отдельный пакет);
• sane-airscan;
• ipp-usb;
• poppler-utils.

Особенности вашего HP
---------------------
Для USB используется локальный sane-airscan через ipp-usb:

  airscan:eN:HP LaserJet Pro M428f [MFP-YUR] (USB) ... ip=127.0.0.1

Прямой backend:

  escl:http://localhost:60000

намеренно не используется, потому что на этом МФУ он терял страницы
автоподатчика.

Горячие клавиши
---------------
Ctrl+P — сканировать
Ctrl+O — импортировать изображения
Ctrl+S — сохранить
Delete — удалить выбранную страницу
Ctrl+Left / Ctrl+Right — повернуть
Alt+Up / Alt+Down — изменить порядок

Ускорение и исправление 0.3.2
-----------------------------
• Исправлена ошибка архива 0.3.1: внутри него по ошибке оставался naps3.py 0.3.0.
• Установщик останавливает старый процесс и проверяет установленную версию.
• После первого обнаружения сохраняются локальный eSCL URL и рабочий профиль.
• При запуске выполняется только короткая проверка 127.0.0.1.
• Для сканирования используется отдельная конфигурация SANE только с airscan.
• Четыре попытки заменены локальным обновлением и максимум одним полным восстановлением.

Исправления 0.3.3
-----------------

• Убраны чёрные полосы вокруг панели параметров: фон viewport и разделители GTK оформляются системной темой.

Изменения интерфейса 0.3.4

• Удалён вложенный Gtk.Paned, который в теме РЕД ОС отображался широкой чёрной полосой.
• Между предпросмотром и настройками теперь используется аккуратный системный разделитель шириной один пиксель.
• Блок рабочего устройства переработан в карточку со значком, названием МФУ, состоянием, способом подключения и локальным адресом.

• Ширина панели параметров увеличена до 330 пикселей для более комфортного отображения.

Исправление запуска 0.3.5

• Удалено неподдерживаемое GTK 3 CSS-свойство, из-за которого версия 0.3.4 могла завершаться до появления окна.

Исправление правой панели 0.3.6
-------------------------------
• Устранена чёрная окантовка правой панели в оконном режиме.
• Для панели настроек теперь используется явный Gtk.Viewport и отдельная светлая поверхность.
• Разделитель между предпросмотром и параметрами жёстко ограничен шириной 1 пиксель.
• Карточка «Рабочее устройство» стала аккуратнее и лучше вписывается в тему РЕД ОС.
• Ширина панели немного увеличена для более комфортного отображения.

Компактная компоновка 0.3.7
---------------------------
• Панель параметров теперь фиксированной ширины 314 пикселей и прилегает к правой границе окна.
• Убрано большое пустое пространство вокруг параметров.
• Добавлена кнопка «Параметры»: она скрывает правую панель и отдаёт всё место предпросмотру.
• Видимость панели сохраняется между запусками.
• Левая панель страниц стала немного уже.
• Внутренние отступы и расстояния между полями уменьшены.

Перенос между компьютерами 0.3.8
--------------------------------
• Профиль больше не привязан к порту 60000 и airscan:eN одного компьютера.
• При подключении МФУ к другому ПК автоматически определяется новый порт ipp-usb.
• Проверяются только локальные адреса 127.0.0.1; сетевые принтеры не выбираются.
• Локальное airscan-устройство принимается даже без отдельной строки escl:http://localhost.
• Если фильтр не совпал, но найден один локальный USB-сканер, используется он.
• Неактуальный профиль автоматически обновляется при запуске.

Гибридное подключение 0.3.9
---------------------------
• Локальный USB по-прежнему имеет приоритет.
• Если USB отсутствует, автоматически выбирается сетевой HP LaserJet Pro M428/M429.
• Локальный псевдоним MFP-YUR не мешает обнаружению той же модели по сети.
• Другой сетевой сканер, например M227, автоматически не выбирается.
• Карточка показывает фактическое подключение: USB или сеть.
• Сетевой IP сохраняется и отображается.

Потоковое сканирование и сеть 0.4.0
----------------------------------
• Добавлен прямой eSCL-движок для автоподатчика.
• Все страницы забираются в рамках одного ScanJob; после успешной страницы следующая запрашивается сразу, без фиксированной паузы sane-airscan.
• Ожидание 50 мс применяется только когда само МФУ отвечает Busy/503.
• Изображения передаются как JPEG для уменьшения объёма, затем параллельно преобразуются в PNG для предпросмотра.
• При несовместимости прямого eSCL автоматически включается прежний SANE-режим.
• Добавлена кнопка «Подключить по сети…» со списком найденных МФУ и ручным вводом IP/имени хоста.
• Сетевой профиль сохраняет URL eSCL и подходит для любого совместимого МФУ.
• Добавлен переключатель «Потоковый режим АПД».


USB-подключение 0.4.1
----------------------
• Добавлена отдельная кнопка «Подключить по USB…».
• Поиск USB не запускает медленное обнаружение сетевых backend-ов.
• Поддерживаются два USB-пути: ipp-usb/eSCL и HP HPLIP hpaio:/usb.
• HPLIP устанавливается автоматически, если пакет доступен в репозитории.
• Модели HP LaserJet M227/M231 могут использовать прямой hpaio, даже если eSCL через ipp-usb отсутствует.
• Сохранённый сетевой профиль заменяется USB-профилем после нажатия кнопки USB.
• Для hpaio потоковый флажок безопасно переходит на штатный scanimage --batch.

Надёжность и скорость АПД 0.5.0
--------------------------------
• Для локального USB HP M428/M429 прямой localhost eSCL больше не используется:
  он физически протягивал несколько листов, но при повторном запуске мог вернуть
  приложению только одну страницу. USB теперь всегда идёт через scanimage --batch.
• Для сетевого потокового eSCL состояние JobCompleted от предыдущего задания
  больше не считается признаком пустого автоподатчика.
• Завершённый ScanJob больше не удаляется принудительно; DELETE используется
  только при отмене или реальной ошибке.
• Если HP завершил ScanJob, но датчик АПД всё ещё видит бумагу, NAPS3 сам
  создаёт продолжение и добавляет страницы в тот же проект.
• ScannerStatus больше не опрашивается при каждом ответе Busy/404, поэтому
  медленные запросы состояния не складываются в паузы между листами.
• Совместимый SANE-режим при 300 dpi пишет страницы сначала в быстрый PNM,
  а не сжимает PNG перед подачей следующего листа.
• Преобразование рабочих страниц в PNG выполняется параллельно после того,
  как автоподатчик закончил протяжку.
• Каждое сканирование получает уникальную папку, поэтому повторные запуски
  не могут перезаписать файлы предыдущего пакета.
• Добавлен журнал ~/.cache/naps3/scan.log с движком, временем и числом страниц.
• Сохранено исправление сортировки системных диалогов сохранения из 0.4.1.

Исправление сетевого АПД 0.5.1
--------------------------------
• Исправлена потеря второй страницы на HP LaserJet MFP M227sdn по сети.
• Состояние ScannerAdfEmpty больше не завершает ScanJob: оно означает, что
  физический лоток уже пуст, но последняя протянутая страница ещё может
  кодироваться и ожидать выдачи через NextDocument.
• NextDocument теперь имеет приоритет перед медленными запросами состояния.
• ScanJob опрашивается реже и с коротким тайм-аутом, поэтому проверки статуса
  не добавляют многосекундные паузы между страницами при 300 dpi.
• При отсутствии GET ScanJob используется восьмисекундное окно дренирования
  только после последней страницы, а не между листами.
• В журнал добавлены HTTP-код, состояние АПД, JobCompleted и
  ImagesToTransfer для точной диагностики конкретной прошивки МФУ.

Ускорение сетевого АПД 0.5.2
--------------------------------
• На HP LaserJet MFP M227sdn устранено преждевременное завершение
  потокового ScanJob после первой страницы.
• ScannerStatus теперь разбирается по отдельным JobInfo; состояние
  старого задания больше не может оборвать текущее.
• Пока ImagesToTransfer больше нуля, NextDocument продолжает
  забирать уже отсканированные листы, даже если АПД пуст.
• Завершённые и прерванные сетевые задания освобождаются;
  следующий запуск больше не получает HTTP 409/503 и не уходит
  в медленный sane-airscan.
• Долгий HTTP-запрос ограничен 30 секундами и повторяется
  внутри того же ScanJob; пятиминутного зависания больше нет.
• Сетевой M227 не поддерживает BlackAndWhite1: чёрно-белый режим
  теперь сканируется как Grayscale8 и быстро преобразуется
  локально, без Invalid argument и повторных поисков сканера.
• Локальный USB HP M428/M429 по-прежнему не использует прямой eSCL
  и без изменений сканирует через scanimage --batch.

Защита от медленного отката 0.5.3
-----------------------------------
• ScannerCapabilities разбирается отдельно для стекла и АПД.
• У HP M227 стекло поддерживает 600/1200 dpi, но сетевой АПД —
  только до 300 dpi. В ускоренном режиме 600 dpi теперь сразу
  заменяется на максимальные 300 dpi.
• Неподдерживаемый двусторонний АПД блокируется до запуска,
  а источник переключается на односторонний.
• Если ускоренный eSCL получает 409/503, приложение больше не
  переключается молча на SANE, который сканировал три листа
  в 600 dpi около 155–158 секунд.

Ручной дуплекс 0.6.0
----------------------
• Добавлен источник «Автоподатчик, ручной дуплекс» для МФУ
  без аппаратного двустороннего сканирования.
• Первый проход сканирует все лицевые стороны, затем NAPS3
  показывает пошаговую инструкцию по перевороту стопки.
• После второго прохода страницы автоматически чередуются:
  лицо 1, оборот 1, лицо 2, оборот 2 и так далее.
• В версии 0.6.1 стопку можно взять ровно так, как её выдало МФУ,
  и сразу положить обратно без ручной сортировки листов.
• Порядок второго прохода автоматически разворачивается, а каждая
  оборотная страница поворачивается на 180°.
• Если число сторон в двух проходах не совпало, ни один скан не
  удаляется: непарные страницы помещаются в конец.

USB M428/M429 0.6.2
-------------------
• Если ipp-usb был замаскирован, установщик теперь снимает
  маску и запускает службу.
• При активном ipp-usb дубль hpaio не показывается.
• hpaio принимается как запасной USB-backend только после
  успешного открытия устройства.
• Контрольный USB-скан со стекла: A4, 300 dpi, RGB,
  2480×3508 — успешно.

Обычный пользователь и дуплекс 0.6.3
------------------------------------------
• Пароль администратора нужен только один раз при установке.
• Запущенный NAPS3 не вызывает sudo, pkexec или systemctl.
• После подключения считываются возможности АПД.
• Для M428/M429 показывается аппаратный дуплекс.
• Для M227 аппаратный дуплекс скрыт, а вместо него доступен
  ручной двухпроходный режим.

Ускорение USB-дуплекса 0.6.4
-------------------------------
• Отключена отладочная трассировка каждого 4096-байтного USB-чтения.
• Отключены DNS-SD-повторы при явном локальном eSCL-адресе.
• Пакетный SANE-буфер увеличен до 1024 КБ.
• Исключён пятисекундный ошибочный первый запуск airscan:eN.

Исправление USB-транспорта M428/M429 0.6.5
------------------------------------------
• В РЕД ОС 8 системный ipp-usb 0.9.27 делал паузу 10 мс после каждого
  нулевого USB-пакета. M428/M429 отправляет такой пакет почти через каждые
  8 КиБ цветной страницы, поэтому сложные стороны задерживались сильнее.
• Добавлена актуальная сборка ipp-usb с большим входным буфером и обработкой
  границ USB burst без искусственной паузы.
• Оптимизация включается только для точного USB VID:PID 03f0:c32a. На другие
  принтеры она не влияет.
• Сохраняется надёжный scanimage --batch: все стороны по-прежнему собираются
  одним заданием, поэтому исправление не возвращает старую потерю страниц.
• Системный бинарник пакета не перезаписывается. Установщик подключает сборку
  через systemd drop-in, а удаление NAPS3 возвращает штатный ipp-usb.

Версия

0.8.4

Изменения 0.8.4
---------------
• Проверка сохранённого сканера при запуске временно блокирует кнопку
  сканирования, поэтому два процесса scanimage больше не открывают Canon
  одновременно.
• Повторный поиск устройства также блокирует начало сканирования до завершения.
• При кратком ответе Device busy локальный SANE выполняет один повтор через
  секунду на том же выбранном устройстве без общего поиска других МФУ.

Изменения 0.8.3
---------------
• Результат scanimage теперь считается успешным только при нулевом коде
  завершения и полном декодировании изображения.
• Сканирование со стекла через SANE пишет универсальный PNM, после чего NAPS3
  проверяет весь поток и атомарно создаёт рабочий PNG.
• Оборванная страница не добавляется в проект. Даже если повреждённый файл
  появился другим путём, предпросмотр сообщает об этом один раз без цепочки
  модальных окон и зависания интерфейса.
• Пакет SANE ограничен 200 страницами, в памяти хранятся только последние
  диагностические строки, а GTK получает только сообщения о ходе сканирования.
• При 600 dpi страницы преобразуются последовательно, чтобы несколько больших
  изображений не занимали память одновременно.
• Диагностика из sane-find-scanner теперь объясняет нехватку USB-прав и
  отсутствующий backend для устройств разных производителей.

Изменения 0.8.2
---------------
• Canon MF4410 уже определялся драйвером pixma, но правило uaccess не выдавало
  права пользователю в удалённой графической сессии.
• Новое позднее udev-правило разрешает доступ только USB-устройству Canon с
  идентификатором 04a9:2737.
• Установщик сразу исправляет режим уже подключённого USB-узла, поэтому выход
  из системы или перезагрузка не требуются.
• Backend pixma проверяется отдельно, даже если системный dll.conf его не
  перечисляет. Пакет аппаратных SANE-драйверов стал обязательной зависимостью.

Изменения 0.8.1
---------------

• Удалены автоматически подставлявшиеся фильтр MFP-YUR, название HP M428 и
  приоритет LaserJet при выборе из нескольких устройств.
• В РЕД ОС локальный поиск использует установленные SANE-драйверы. Canon
  MF4410 определяется backend'ом pixma и больше не отбрасывается как не-HP.
• Для каждого SANE-профиля сохраняются точные названия стекла и АПД, которые
  сообщает его драйвер.
• RPM устанавливает udev-правило для Canon MF4410 (USB 04a9:2737), найденного
  в диагностике пользователя без прав доступа.
• Недоступный старый автоматический профиль MFP-YUR удаляется. Остальные
  выбранные профили сохраняются и не заменяются другим МФУ.

Изменения 0.8
-------------
• Добавлена отдельная сборка для Windows 10/11 x64 с тем же GTK-интерфейсом,
  обработкой страниц, импортом и защищённым сохранением.
• Установленные сканеры Windows обнаруживаются через Windows Image Acquisition.
• Сканирование со стекла, АПД и аппаратный дуплекс выполняются через точный WIA
  DeviceID выбранного устройства.
• После ответа «занят», «не в сети», «прогревается» или ложного «нет бумаги»
  выполняется один повтор на том же МФУ, что помогает при выходе из сна.
• Windows-пакет включает GTK 3, Pillow и pdftoppm; отдельная установка Python
  пользователю не нужна.
• Linux backend SANE/eSCL, исправленный ipp-usb и все функции 0.7 сохранены.

Изменения 0.7
-------------
• При восстановлении текущего задания программа остаётся на выбранном МФУ и
  не запускает сканирование на другом найденном устройстве.
• Проверка сохранённого профиля при запуске не заменяет его доступным USB-МФУ.
• Во время сохранения заблокированы поворот, порядок, удаление и очистка страниц,
  включая соответствующие горячие клавиши.
• PDF, TIFF и отдельные файлы сначала полностью записываются во временные файлы.
  Существующие файлы заменяются после успешной записи; при ошибке выполняется
  откат уже сделанных замен.
• При закрытии документа с изменениями предлагается сохранить его, закрыть без
  сохранения или отменить закрытие.

Изменения 0.6.6
----------------
• Отмена пакетного сканирования останавливает всю группу backend-процессов.
  Если мягкая остановка не сработала, выполняется принудительная.
• Сетевой eSCL-ответ закрывается вне GTK-потока, поэтому окно не замерзает.
• Частичная страница после отмены не попадает в проект.
• Выделение страницы сохраняется после поворота.


Отдельные PDF 0.6.7
--------------------
• В режиме «Все страницы отдельными изображениями» в список форматов
  добавлен PDF.
• При выборе PDF каждая отсканированная страница сохраняется в свой
  одностраничный файл: имя-001.pdf, имя-002.pdf и далее.
• PDF выбран по умолчанию в выпадающем списке форматов.
• Остальные форматы PNG, JPEG, TIFF, BMP и WebP сохранены.
