# NAPS3 для РЕД ОС и Windows

GTK-приложение для сканирования документов через USB и сеть. Поддерживает
стекло, автоподатчик, ручной и аппаратный дуплекс, импорт страниц и сохранение
в PDF, TIFF, PNG, JPEG, BMP и WebP.

Текущая версия исходного кода — **0.8.3** для **РЕД ОС 8 x86_64** и **Windows 10/11 x64**.
Интерфейс, работа со страницами и защищённое сохранение общие для обеих ОС.
В РЕД ОС используются SANE/eSCL, в Windows — установленный системный драйвер WIA.

## Windows

Скачайте установщик из последнего выпуска и запустите его:

- [NAPS3-latest-Windows-x64.exe](https://github.com/Kostya5232/naps3-redos/releases/latest/download/NAPS3-latest-Windows-x64.exe)
- [все файлы выпуска и контрольные суммы](https://github.com/Kostya5232/naps3-redos/releases/latest)

Установка выполняется для текущего пользователя и не требует покупки лицензии
или отдельной подписки. Если сканер не появляется в списке, установите WIA-драйвер
производителя МФУ. Для переносного запуска в выпуске также есть ZIP-архив.

Windows-пакет пока не подписан коммерческим сертификатом, поэтому SmartScreen
может показать стандартное предупреждение для нового издателя. SHA-256 каждого
файла публикуется рядом с установщиком.

## РЕД ОС: установка одной командой

Прямо из выпуска GitHub:

```bash
sudo dnf install -y https://github.com/Kostya5232/naps3-redos/releases/latest/download/naps3-latest.x86_64.rpm
```

Чтобы получать следующие версии обычной командой `dnf upgrade`, один раз
подключите бесплатный репозиторий:

```bash
sudo curl -fsSL https://kostya5232.github.io/naps3-redos/naps3.repo -o /etc/yum.repos.d/naps3.repo && sudo dnf install -y naps3
```

После этого обновление выполняется вместе с системой:

```bash
sudo dnf upgrade
```

Репозиторий пока публикуется без RPM-подписи (`gpgcheck=0`). Пакеты и метаданные
передаются по HTTPS, а GitHub Release дополнительно содержит SHA-256.

## Что изменилось в 0.8.3

- сканирование со стекла через SANE получает универсальный PNM и проверяет
  завершение `scanimage` до создания страницы;
- полученное изображение полностью декодируется и атомарно преобразуется в PNG;
- оборванная страница не добавляется в проект и не вызывает лавину окон GTK;
- служебный вывод SANE ограничен последними строками, а интерфейс обновляется
  только при реальном прогрессе;
- одно пакетное задание ограничено 200 страницами, а обработка 600 dpi выполняется
  последовательно для защиты памяти;
- USB-диагностика теперь объясняет нехватку прав и отсутствие backend для
  сканеров любых производителей.

## Что изменилось в 0.8.2

- исправлены права Canon MF4410 в удалённых графических сессиях;
- позднее udev-правило выдаёт доступ только USB-устройству `04a9:2737`;
- установщик сразу применяет права к уже подключённому Canon;
- backend `pixma` проверяется отдельно, даже если отсутствует в `dll.conf`;
- RPM обязательно устанавливает пакет аппаратных SANE-драйверов.

## Что изменилось в 0.8.1

- удалены автоматический фильтр `MFP-YUR` и приоритет HP при выборе сканера;
- Linux теперь видит установленные локальные SANE-драйверы, включая Canon `pixma`;
- сохраняются точные названия источников конкретного SANE-драйвера;
- добавлено правило доступа для Canon MF4410 с USB ID `04a9:2737`;
- недоступный старый автоматический профиль HP удаляется после проверки.

## Что изменилось в 0.8

- добавлена сборка Windows с обнаружением и сканированием через WIA;
- повтор после сна выполняется на том же выбранном устройстве WIA;
- Windows-установщик включает GTK 3, Pillow и `pdftoppm`;
- сохранены все функции версии 0.7 и Linux backend SANE/eSCL;
- GitHub Actions отдельно проверяет и собирает обе платформы.

Полная история и описание возможностей находятся в [README.txt](README.txt),
а устройство исходного кода — в [PROGRAM_MAP.md](PROGRAM_MAP.md).

## Проверка и сборка

Linux:

```bash
python3 -m unittest discover -s tests -p 'test_*.py'
./build_rpm.sh
```

Windows собирается в окружении MSYS2 UCRT64:

```bash
./windows/build_windows.sh
powershell.exe -File windows/build_installer.ps1
```

Теги вида `v0.8.3` запускают GitHub Actions: тесты, сборку RPM, сборку Windows EXE
и ZIP, создание общего выпуска и обновление DNF-репозитория на GitHub Pages.
