NAPS3 0.8.3 — локальная проверка Canon MF4410
================================================

Эта версия не опубликована в GitHub и предназначена для проверки на компьютере
с РЕД ОС, где уже установлен NAPS3 0.8.1.

1. Распакуйте архив:

   tar -xzf naps3-0.8.3-canon-scanfix.tar.gz
   cd naps3-0.8.3-local

2. Включите Canon MF4410, подключите его по USB и выполните:

   sudo bash update_naps3_app.sh

   Ожидаемая строка для подключённого устройства:
   Canon MF4410: права 0666 применены к /dev/bus/usb/BBB/DDD

   Если backend pixma ещё не установлен, обновлятор сначала бесплатно загрузит
   пакет sane-backends-drivers-scanners из системного репозитория РЕД ОС.

3. Запустите NAPS3 обычным пользователем. В правом нижнем углу должна быть
   версия 0.8.3. Нажмите «Подключить сканер…» и выберите Canon MF4410.

4. Положите документ на стекло и выполните короткую проверку: цветной режим,
   150 dpi, A4. Успешная страница должна сразу появиться в предпросмотре.

   Если pixma снова передаст оборванный файл, NAPS3 должен показать одно окно
   «Ошибка сканирования», не добавлять пустую страницу и остаться отзывчивым.
   Повторяющихся окон «Не удалось показать страницу» быть не должно.

Быстрая проверка вне программы:

   scanimage -L

В выводе ожидается устройство с началом имени pixma:04A92737.

Обновлятор сохраняет предыдущий naps3.py рядом с установленным файлом и
показывает полный путь резервной копии. RPM-база останется на версии ранее
установленного пакета до будущего официального RPM 0.8.3.
