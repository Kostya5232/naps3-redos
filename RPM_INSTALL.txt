NAPS3 0.9.0 — РЕД ОС и Windows
==================================================

Установка или обновление на РЕД ОС 8 x86_64:

  cd dist
  sha256sum -c SHA256SUMS
  sudo dnf install ./naps3-0.9.0-1.red80.x86_64.rpm

DNF обновит более раннюю RPM-версию с сохранением пользовательских настроек.
После установки полностью закройте старое окно NAPS3 и запустите приложение
снова. Проверить версию можно в нижнем правом углу окна.

Изменения версии 0.9.0:

* Printer Doctor может безопасно назначить проверенный сканер рабочим в NAPS3;
* CLI принимает точный SANE ID или IP/eSCL URL, повторно проверяет устройство и
  не запускает общий поиск других МФУ;
* settings.json заменяется атомарно, перед изменением сохраняется резервная копия;
* регистрация запрещена от root и при открытом окне NAPS3.

Команды интеграции:

  naps3 --register-scanner --device-id 'pixma:идентификатор' --name 'Canon'
  naps3 --register-scanner --device-id 'airscan:e0:Office' --connection network --name 'Office'
  naps3 --register-scanner --address 192.168.1.50 --name 'Сетевой МФУ'

Изменения версии 0.8.4:

* запуск сканирования не пересекается с фоновой проверкой Canon;
* повторный поиск временно блокирует кнопку сканирования;
* Device busy получает один повтор на том же выбранном USB-сканере;
* общий поиск при таком повторе не запускается и другое МФУ не выбирается.

Для ручной сборки на РЕД ОС 8:

  ./build_rpm.sh
