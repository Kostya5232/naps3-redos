NAPS3 0.8.2 — РЕД ОС и Windows
==================================================

Установка или обновление на РЕД ОС 8 x86_64:

  cd dist
  sha256sum -c SHA256SUMS
  sudo dnf install ./naps3-0.8.2-1.red80.x86_64.rpm

DNF обновит более раннюю RPM-версию с сохранением пользовательских настроек.
После установки полностью закройте старое окно NAPS3 и запустите приложение
снова. Проверить версию можно в нижнем правом углу окна.

Изменения версии 0.8.2:

* исправлен доступ к Canon MF4410 из удалённой графической сессии;
* позднее udev-правило применяется только к Canon USB 04a9:2737;
* права немедленно применяются к уже подключённому устройству;
* pixma проверяется отдельно и устанавливается как обязательная зависимость;
* выбор сканера, Windows WIA и пути HP не изменялись.

Для ручной сборки на РЕД ОС 8:

  ./build_rpm.sh
