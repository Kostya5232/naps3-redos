NAPS3 0.8.1 — РЕД ОС и Windows
==================================================

Установка или обновление на РЕД ОС 8 x86_64:

  cd dist
  sha256sum -c SHA256SUMS
  sudo dnf install ./naps3-0.8.1-1.red80.x86_64.rpm

DNF обновит более раннюю RPM-версию с сохранением пользовательских настроек.
После установки полностью закройте старое окно NAPS3 и запустите приложение
снова. Проверить версию можно в нижнем правом углу окна.

Изменения версии 0.8.1:

* удалены автоматический фильтр MFP-YUR и приоритет HP;
* локальные сканеры ищутся через установленные SANE-драйверы;
* DNF устанавливает пакет аппаратных SANE-драйверов, если он доступен;
* добавлена поддержка Canon MF4410 через backend pixma;
* пакет настраивает доступ к USB-устройству Canon 04a9:2737;
* Windows WIA и проверенные пути HP через ipp-usb/hpaio сохранены.

Для ручной сборки на РЕД ОС 8:

  ./build_rpm.sh
