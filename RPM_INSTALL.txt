NAPS3 0.7 — безопасное восстановление и сохранение
==================================================

Установка или обновление на РЕД ОС 8 x86_64:

  cd dist
  sha256sum -c SHA256SUMS
  sudo dnf install ./naps3-0.7-1.red80.x86_64.rpm

DNF обновит более раннюю RPM-версию с сохранением пользовательских настроек.
После установки полностью закройте старое окно NAPS3 и запустите приложение
снова. Проверить версию можно в нижнем правом углу окна.

Изменения версии 0.7:

* восстановление не переключает задание на другое найденное МФУ;
* страницы нельзя изменить во время сохранения;
* конечные файлы заменяются только после успешной временной записи;
* при закрытии предлагается сохранить несохранённые страницы и изменения.

Для ручной сборки на РЕД ОС 8:

  ./build_rpm.sh
