NAPS3 0.8.4 — РЕД ОС и Windows
==================================================

Установка или обновление на РЕД ОС 8 x86_64:

  cd dist
  sha256sum -c SHA256SUMS
  sudo dnf install ./naps3-0.8.4-1.red80.x86_64.rpm

DNF обновит более раннюю RPM-версию с сохранением пользовательских настроек.
После установки полностью закройте старое окно NAPS3 и запустите приложение
снова. Проверить версию можно в нижнем правом углу окна.

Изменения версии 0.8.4:

* запуск сканирования не пересекается с фоновой проверкой Canon;
* повторный поиск временно блокирует кнопку сканирования;
* Device busy получает один повтор на том же выбранном USB-сканере;
* общий поиск при таком повторе не запускается и другое МФУ не выбирается.

Для ручной сборки на РЕД ОС 8:

  ./build_rpm.sh
