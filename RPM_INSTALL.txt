NAPS3 0.8.3 — РЕД ОС и Windows
==================================================

Установка или обновление на РЕД ОС 8 x86_64:

  cd dist
  sha256sum -c SHA256SUMS
  sudo dnf install ./naps3-0.8.3-1.red80.x86_64.rpm

DNF обновит более раннюю RPM-версию с сохранением пользовательских настроек.
После установки полностью закройте старое окно NAPS3 и запустите приложение
снова. Проверить версию можно в нижнем правом углу окна.

Изменения версии 0.8.3:

* оборванный ответ Canon pixma отбрасывается до добавления страницы;
* стекло SANE переведено на универсальный PNM с проверкой кода завершения;
* готовый PNG проверяется и заменяется атомарно;
* ошибка предпросмотра больше не создаёт повторяющиеся окна;
* поток служебных сообщений и пакет ограничены для защиты памяти интерфейса;
* диагностика прав и backend стала общей для SANE-сканеров.

Для ручной сборки на РЕД ОС 8:

  ./build_rpm.sh
